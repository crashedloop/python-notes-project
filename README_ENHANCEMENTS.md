## 🎯 Quick Feature Tour

### Creating Notes with Images
```
1. Type your note
2. Click 📷 icon
3. Select images
4. See instant previews
5. Remove unwanted with ×
6. Save!
```

### Creating To-Do Lists
```
1. Click ☑️ icon
2. Type task
3. Repeat for more tasks
4. Save and view
5. Click checkboxes to complete

```
Click the 🌙/☀️ icon in navigation
Everything adjusts automatically
Settings saved in browser
